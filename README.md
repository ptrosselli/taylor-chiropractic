# Taylor Chiropractic & Wellness — GitHub Pages

This folder is a ready-to-upload static website. Keep `index.html`, the other `.html` files, `styles.css`, `main.js`, `taylor-header-icon.png`, and `.nojekyll` together at the **root** of your GitHub repository.

## Publish manually

1. On GitHub, create a new repository. A name such as `taylor-chiropractic` works.
2. Select **Add file → Upload files** and drag the site files from this unzipped folder onto the upload page. Include the hidden `.nojekyll` file if your operating system shows hidden files; the site can also work without it.
3. Select **Commit changes**.
4. Go to **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**, then select branch **main** and folder **/(root)**. Save.
6. Once GitHub Pages finishes publishing, open `https://YOUR-USERNAME.github.io/taylor-chiropractic/` (substitute your GitHub username and repository name).

For updates, upload the changed files to the same repository root and commit. GitHub Pages republishes automatically.

## Notes

- The logo PNG is included, and relative links work under a project URL.
- The phone number, email, hours, and address are concept/demo content; verify and replace with the practice's actual details before sharing publicly.
- The contact form opens a prefilled message in the visitor's email app; it does not send or store submissions on the website. Connect a form service or backend if you need web-based submissions.
- Some photos and fonts are loaded from external providers and require internet access.
